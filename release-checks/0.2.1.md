## Security and dependencies

The final consumer prefix reported 25 moderate entries, no high/critical
entries, and the same two underlying advisories:
`GHSA-3g3m-2fjr-6pw4` and `GHSA-g3hv-75wg-m249`. No forced upgrades or npm
publication were performed. See DEPENDENCIES.md for reachability boundaries.

Automatic closing remains opt-in and disabled by default. Current focus is
protected transiently; explicit `ocap_pin=1` metadata remains protected.
Completion checks preserve running/blocked/uncertain work, pending forms and
permissions, foreign viewers and failed state. Herdr/OpenCode close-vs-click
races are not atomic. Native nested delegation, cold recovery and remote HTTPS
Basic authentication remain unverified.
